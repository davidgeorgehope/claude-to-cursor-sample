# Project instructions (Cursor / AGENTS.md)

This is a sample repo that shows Claude Code skills, hooks, and marketplace
layout working side by side with Cursor-native equivalents.

When reviewing or changing code here:

- Prefer small, reversible edits.
- Do not commit secrets or credentials.
- Treat destructive shell (`rm -rf`, force-push, hard reset) as high risk.
- Use the `secure-commit` skill before creating a commit.

Note: if both `AGENTS.md` and `CLAUDE.md` are present in the same folder,
Cursor prefers `AGENTS.md`.
